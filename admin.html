🔧 Configurar Supabase

Siga os passos abaixo para conectar o cardápio ao banco de dados em nuvem:

1

Acesse supabase.com e crie uma conta gratuita.

2

Crie um novo projeto e aguarde a inicialização.

3

Em Project Settings → API, copie a Project URL e a chave anon public.

4

Abra o arquivo supabase-config.js e substitua SUA_SUPABASE_URL_AQUI e SUA_SUPABASE_ANON_KEY_AQUI.

5

Em SQL Editor no Supabase, execute o SQL que está nos comentários do arquivo supabase-config.js.
